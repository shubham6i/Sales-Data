# Sales Data Analysis

## About
This project analyzes sales data using SQL, Python, Pandas, and MySQL.

## Tools
- Python
- Pandas
- SQL
- MySQL
- Jupyter Notebook

## Analysis
- Top-selling products
- Sales by region
- Sales by category
- Sales by year
- Profit analysis
- CTE-based queries

## Goal
To practice SQL and analyze sales data to find useful insights.
